# Support

For setup and expected behavior, start with the [README](README.md), [Installation](docs/INSTALLATION.md), and [FAQ](docs/FAQ.md).

## Where to ask

- **Usage question:** Open a GitHub issue with the `question` prefix in the title, your host agent/version, install scope, and the exact step that is unclear.
- **Bug report:** Use the GitHub bug-report issue template with a minimal, sanitized reproduction.
- **Feature proposal:** Use the feature-request issue template and explain the user outcome.
- **Security-sensitive report:** Follow [SECURITY.md](SECURITY.md); do not disclose exploit details or credentials in a public issue.

This is a community-maintained repository; no response-time or support SLA is promised.
