# Roadmap

This is an **aspirational roadmap**, not evidence that features below are already implemented. The initial repository baseline contains a portable SKILL.md, documentation, examples, installation tooling, and validation checks.

## Near-term candidates

- [ ] Add structured behavioral evaluations with an explicit set of annotated prompts and expected decision/coverage outcomes.
- [ ] Test compatibility under specific Cursor, Claude Code, and Codex versions and document observed differences.
- [ ] Add versioned A2A schema artefacts and machine-readable fixture validation if the use case justifies them.
- [ ] Formalise a release/versioning policy after initial feedback.
- [ ] Owner to choose a distribution license.
- [ ] Publish installation or marketplace integrations only after verifying each vendor's packaging and permissions.

## Longer-term candidates

- [ ] Scenario benchmarks for branch recovery, post-merge hardening, decision gating, and conflict resolution.
- [ ] Automated traceability coverage checks against sample project specifications.
- [ ] Optional distribution tooling that avoids duplicating skills in multi-agent workspaces.
- [ ] Maintain version-specific compatibility notes based on reproducible evidence.

## Principles for accepting roadmap changes

New capabilities must solve a demonstrated problem, avoid speculative product claims, preserve human control over material decisions, respect project data boundaries, and include objectively testable acceptance criteria.

Discussion and proposals belong in GitHub Issues; roadmap entries are not commitments or release dates.
